# BHDS Lab 홈페이지 — 관리 & 인수인계 매뉴얼

연세대학교 **바이오헬스 데이터사이언스 연구실 (Biostatistics & Health Data Science Lab, 박소희 교수님 연구실)** 홈페이지 소스코드입니다.

- 주소: https://bhds-lab-ashy.vercel.app
- 코드: GitHub `zarong94/bhds-lab` (main 브랜치에 올리면 Vercel이 1~2분 안에 자동 배포)
- 내용: 구글 드라이브 `homepage` 폴더의 시트 **"BHDS 홈페이지 내용"** + 사진 폴더

**글·사진 수정에는 코드가 필요 없습니다.** 시트와 드라이브만 고치면 보통 3분 안에 사이트에 반영됩니다.
메뉴 구성·화면 배치·새 기능처럼 디자인/구조를 바꿀 때만 코드를 고칩니다.

## 1. 사이트 구성 (메뉴)

| 메뉴 | 하위 메뉴 (마우스를 올리면 펼침) | 주소 | 내용이 오는 시트 탭 |
|---|---|---|---|
| Home | — | `/` | 홈, 연구분야, 연구과제, 소식 |
| Professor (교수 소개) | Profile (교수 소개) | `/about` | 교수소개 |
| | Teaching (강의) | `/teaching` | 수업 |
| Research (연구) | Research Areas (연구 분야) | `/research/areas` | 연구분야 |
| | Projects (연구 과제) | `/research/projects` | 연구과제 |
| | Papers (논문) | `/research/papers` | 논문 |
| | Student Presentations (학생 학술발표) | `/research/presentations` | 학술발표 |
| Members (구성원) | — | `/members` | 구성원 (+ 홈 탭의 구성원 사진) |
| News (소식) | — | `/news` | 소식 |
| Contact Us (연락처) | — | `/contact` | 홈 (주소·이메일·모집) |

- 예전 주소 `/research`, `/publications`, `/publications?tab=presentations` 로 들어와도 새 페이지로 자동 연결됩니다.
- 오른쪽 위 `EN | KR` 버튼으로 언어 전환. **한국어 화면은 한국어만, 영어 화면은 영어만** 나오도록 되어 있어서, 시트의 `(영문)` 칸을 채워야 영어 화면에도 나옵니다.

### 홈 화면 순서

1. **첫 화면**: 흐린 배경(홈 탭 `대표 사진`) + 왼쪽에 학교명·연구실 이름·연구분야(가운데 점으로 나열)·버튼, 오른쪽에 **소식 슬라이드**
   - 소식 탭에서 사진이 있는 소식(최근 6개)이 5초마다 넘어갑니다. 누르면 소식 페이지로 이동.
   - 좌우로 밀기 / 트랙패드 옆 스크롤 / 아래 긴 막대 클릭으로 넘길 수 있고, 마우스를 올리면 멈춥니다.
   - 사진 있는 소식이 하나도 없으면 `대표 사진`이 나옵니다.
2. **연구실 소개 (About us)**: 홈 탭의 소개 문구, 연구책임자, 소속
3. **연구 분야**: 연구분야 탭 카드
4. **함께한 기관**: 연구과제 탭의 `지원기관` 칸에서 기관 이름을 자동으로 뽑아 한 줄로 흐르게 보여줌 (가운데에서 크고 선명, 양옆으로 갈수록 작고 흐림)
5. **연락처**: 주소, 이메일, 모집 분야, 이메일 문의·오시는 길 버튼

## 2. 내용 수정하기 (가장 자주 쓰임)

1. 드라이브 `homepage` 폴더의 시트 **"BHDS 홈페이지 내용"** 을 엽니다.
2. 해당 탭을 고칩니다. 시트 첫 탭 **사용법** 에 작성 규칙이 정리돼 있습니다.
3. 최대 약 3분 뒤 새로고침하면 보입니다.

> - 탭 이름과 각 탭 첫 줄(열 제목)은 바꾸지 마세요. 사이트가 이 이름으로 내용을 찾습니다.
> - 숨기고 싶은 줄은 `공개` 칸에 `N`. `(예시)`로 시작하는 줄도 안 보입니다.

### 홈 탭의 주요 줄

| 항목 | 설명 |
|---|---|
| 대표 사진 / 대표 사진 위치 | 첫 화면 흐린 배경 사진 (`main` 폴더 파일 이름). 위치: `위`·`가운데`·`아래` 또는 `0~100` 숫자(%) |
| 구성원 사진 / 구성원 사진 위치 | 구성원 페이지 맨 위 단체 사진. 비워 두면 `IMG_0940.jpeg`(경주 사진) |
| 구글스칼라 | 논문 페이지의 Google Scholar 버튼 주소 |
| 모집 분야 | 쉼표로 구분 (예: 석사과정, 박사과정, 박사후연구원) → 연락처에 칩으로 표시 |
| 주소 | 연락처·지도에 쓰임 |

(`띠 사진` 줄은 예전 홈 화면용으로, 지금은 쓰이지 않습니다.)

### 사진 폴더 (`homepage` 안)

| 폴더 | 용도 | 시트에 적는 곳 |
|---|---|---|
| `member` | 구성원·교수님 사진 | 구성원/교수소개 탭 `사진파일명` |
| `news` | 소식 사진 (홈 첫 화면 슬라이드에도 나옴) | 소식 탭 `사진파일명` |
| `main` | 홈 배경·구성원 단체 사진 | 홈 탭 `대표 사진`, `구성원 사진` |
| `logo` | 함께한 기관 로고 | 적을 필요 없음 — **파일 이름을 기관 이름으로** (예: `국립암센터.png`, `한국과학기술연구원(KIST).jpg`) |

- 파일 이름은 시트에 적은 것과 **확장자까지 똑같이**. (맥에서 올린 한글 파일 이름도 인식됩니다.)
- 로고는 주변 여백을 사이트가 자동으로 잘라내고 크기를 맞춥니다. 로고 하나만 들어 있는 파일을 올려 주세요(여러 로고가 모인 안내용 이미지 X). 배경이 투명한 PNG·SVG도 됩니다.
- 같은 이름으로 사진을 **덮어쓰면** 구글 쪽 저장본 때문에 반영이 늦을 수 있습니다. 바로 바꾸려면 기존 파일을 지우고 새로 올리거나 이름을 바꾸세요.
- 사진을 잠깐 못 불러오면 드라이브 미리보기 주소로 한 번 더 시도합니다. 그래도 안 되면 이니셜이 나옵니다(몇 분 뒤 새로고침).

### 구성원 사진 크기 맞추기

구성원 탭에 `사진 크기` 열(숫자 %, 기본 100)과 `사진 위치` 열을 만들면 사람별로 얼굴 크기·보이는 부분을 조절할 수 있습니다.
시트에 값이 없으면 코드 기본값을 씁니다 (`src/context/SiteDataContext.jsx` 의 `PHOTO_ZOOM`, 현재 김지수 128%).

### 자동으로 처리되는 것

- **함께한 기관**: 연구과제 탭 `지원기관` 칸을 `·`로 나눠 `…부/청/센터/재단/연구원/진흥원/공단`으로 끝나는 이름만 뽑습니다. 과제 수가 많은 순. 영어 이름은 코드의 `ORG_EN` 표에 있는 기관만 영어 화면에 나옵니다 — 새 기관이 생기면 표에 추가하세요.
- **교신저자 표시**: 논문 탭 `저자역할`이 `교신저자`인데 저자 목록이 `et al.`로 끝나 `Park S`가 빠진 경우, 끝에 `…, Park S.`를 붙여 굵게 표시합니다. (공동저자 논문은 저자 칸에 전체 저자를 적어야 교수님 이름이 보입니다.)
- **구성원**: 교수님은 구성원 페이지에서 빠지고(교수 소개 페이지에 있음), 졸업생은 `대학원` 칸(융합보건의료대학원 / 보건대학원)으로 나뉩니다.

## 3. 어떻게 연결돼 있나

```
구글시트 + 드라이브 사진 폴더 (homepage 및 하위 폴더 전체)
        │  (Apps Script 웹 앱: "BHDS 홈페이지 연결")
        ▼
 JSON 주소 (src/config.js 의 SHEET_API_URL)
        │  방문자 브라우저가 페이지를 열 때 읽어 옴 (스크립트가 3분간 캐시, 주소 뒤 ?fresh=1 이면 즉시 새로 읽음)
        ▼
 홈페이지 (GitHub → Vercel 자동 배포)
```

- **Apps Script**: 코드 사본은 `apps-script/Code.gs`. script.google.com 의 "BHDS 홈페이지 연결" 프로젝트.
  고친 뒤에는 **배포 → 배포 관리 → 수정(연필) → 버전: 새 버전 → 배포** 를 눌러야 반영됩니다. (주소는 그대로)
- **안전장치**: 시트가 잠시 응답하지 않으면 방문자 브라우저에 저장된 마지막 내용 → 없으면 `src/data/snapshot.json` 을 보여줍니다.
  `snapshot.json` 은 Vercel 배포 때마다 시트에서 자동으로 새로 받아옵니다(`scripts/refresh-snapshot.mjs`).
- **사진 주소**: 드라이브 파일 ID로 `lh3.googleusercontent.com/d/<ID>` 이미지를 불러옵니다. `homepage` 폴더가 **"링크가 있는 모든 사용자 — 보기"** 로 공유돼 있어야 합니다.

## 4. 코드 구조 (개발자용)

```
src/
├── config.js                    # 시트 연결 주소, 사진 주소 규칙
├── App.jsx                      # 페이지 주소(라우트), 예전 주소 연결, #위치 스크롤
├── context/SiteDataContext.jsx  # 시트 내용 불러오기·정리 (탭 → 화면용 데이터)
│                                #   pick/period 등 한·영 선택, 기관 추출(ORG_EN), PHOTO_ZOOM, 교신저자 처리
├── context/LanguageContext.jsx  # 한국어/영어 전환 (기본 한국어)
├── i18n/ko.json, en.json        # 메뉴·버튼 등 고정 문구 (메뉴 이름은 nav.*)
├── data/snapshot.json           # 시트 내용 백업본 (자동 갱신)
├── components/
│   ├── Navbar.jsx/.css          # 메뉴 + 하위 메뉴 (메뉴 순서·구성은 links 배열)
│   ├── Photo.jsx                # 드라이브 사진 (실패 시 예비 주소 → 이니셜)
│   ├── PageHero.jsx, Footer.jsx, NewsCard.jsx
└── pages/
    ├── Home.jsx/.css            # 첫 화면(HeroNews 슬라이드), 소개, 연구 분야, 함께한 기관(PartnerArc, OrgLogo), 연락처
    ├── About.jsx                # 교수 소개
    ├── Members.jsx              # 구성원 (맨 위 단체 사진, 타원형 사진)
    ├── Research.jsx             # view="areas" | "projects"
    ├── Publications.jsx         # view="papers" | "presentations"
    ├── Teaching.jsx, News.jsx, Contact.jsx
apps-script/Code.gs              # 시트 → JSON 스크립트 사본
```

```bash
npm install
npm run dev     # 로컬 개발 서버
npm run build   # 배포용 빌드 (빌드 전에 snapshot 자동 갱신)
```

디자인 기준: 남색·파랑 계열, 주황 포인트 없음, AI 느낌 아이콘 대신 번호·글자 위주, 사진은 테두리 대신 아래로 은은한 그림자.

## 5. 다른 사람(또는 다른 Claude)에게 넘길 때

- **내용만 고칠 사람**: `homepage` 폴더와 시트를 편집자로 공유하면 끝.
- **코드를 고칠 사람**: GitHub 저장소 Settings → Collaborators 로 초대. main 에 올리면 자동 배포됩니다.
  Vercel 설정까지 맡길 때만 Vercel 프로젝트에 초대.
- **다른 Claude에게 맡길 때**: 이 저장소를 연결하고 "README 보고 이어서 작업해줘"라고 하면 됩니다.
- **담당자가 완전히 바뀔 때**
  - [ ] 드라이브 `homepage` 폴더·시트 소유권 이전
  - [ ] Apps Script "BHDS 홈페이지 연결" 소유권 이전 (만든 사람 계정으로 실행됨 — 새 담당자 계정으로 다시 배포했다면 `src/config.js` 의 주소 교체)
  - [ ] GitHub 저장소 Settings → Transfer, Vercel 프로젝트 이전
  - [ ] 연세대학교 도메인 연결이 필요하면 학교 전산원에 CNAME 등록 요청
